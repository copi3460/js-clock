# Specialtegn brugt i script.js

Her er en oversigt over de vigtigste specialtegn, der bruges i [script.js](script.js), med deres navn:

| Tegn | Navn | Forklaring |
|---|---|---|
| `.` | punktum / dot | bruges til at få adgang til egenskaber og metoder |
| `(` og `)` | parenteser / parentheses | bruges til funktionskald og grupperinger |
| `[` og `]` | firkantede parenteser / square brackets | bruges til arrays og indeksering |
| `{` og `}` | krøllede parenteser / curly braces | bruges til kodeblokke |
| `;` | semikolon | afslutter en JavaScript-sætning |
| `,` | komma | adskiller værdier og argumenter |
| `=` | lighedstegn / equals sign | tildeler værdi |
| `+` | plus | addition |
| `-` | minus | subtraktion og negative tal |
| `*` | gangetegn / asterisk | multiplikation |
| `/` | skråstreg / slash | division |
| `"` | anførselstegn / double quote | bruger til tekststrenge |
| `'` | apostrof / single quote | bruger til tekststrenge og enkelte tegn |
| `#` | hashtag / hash | bruges i farvekoder som `#333` |
| `:` | kolon | bruges i objekter og værdier |
| `<` | mindre end | sammenligning |
| `>` | større end | sammenligning |
| `!` | udråbstegn / exclamation mark | bruges i logiske udtryk |
| `?` | spørgsmålstegn / question mark | bruges i betingelser og ternære udtryk |

Disse tegn bruges i JavaScript-koden til at definere funktioner, arrays, betingelser, matematiske udtryk, tekststrenge og farvekoder.
